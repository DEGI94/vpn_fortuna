# @vpn_fortuna

Автоматическая сборка публичных VPN-подписок каждые 4 часа.

## Подписки

- [Небольшая тестовая подписка для v2rayNG — 100 VLESS](https://raw.githubusercontent.com/DEGI94/vpn_fortuna/main/subscriptions/v2rayng-test.base64.txt)

В v2rayNG добавьте URL через **Настройки подписки → +**, сохраните и выполните
**Обновить подписки** на главном экране. Тестовая подписка помогает проверить импорт
без загрузки общего списка из десятков тысяч записей. Это не список проверенных рабочих серверов.

- [Общая подписка](https://raw.githubusercontent.com/DEGI94/vpn_fortuna/main/subscriptions/all.txt)
- [Общая подписка Base64](https://raw.githubusercontent.com/DEGI94/vpn_fortuna/main/subscriptions/all.base64.txt)
- [Файлы по протоколам](subscriptions/protocols)
- [Файлы по транспортам](subscriptions/transports)
- [TLS / Reality](subscriptions/security)
- [Протокол → транспорт → защита](subscriptions/combined)
- [Статистика и состояние источников](subscriptions/stats.json)

Добавьте raw-ссылку нужного файла в VPN-клиент как подписку. Все конфигурации называются `@vpn_fortuna`.
Для каждой группы создаются обычный TXT и Base64 TXT; пустые группы не создаются.

Поддерживаются VLESS, VMess (Base64 JSON), Trojan, Hysteria, Hysteria2 / hy2, TUIC и Shadowsocks.
WS, gRPC, XHTTP и другие транспорты определяются по параметрам конфигураций. Reality и TLS сортируются отдельно.

## Обновление

[GitHub Actions](https://github.com/DEGI94/vpn_fortuna/actions/workflows/update.yml) запускается в 00:17, 04:17, 08:17, 12:17, 16:17, 20:17 UTC.
Также доступна кнопка **Run workflow**. GitHub может задерживать плановые запуски; это не точный таймер.
В неактивных публичных репозиториях GitHub может отключить расписание после 60 дней без активности.

Источники перечислены в [sources.txt](sources.txt). Сбой отдельного источника не стирает его последнюю успешную копию:
она хранится в `.source-cache`, а дата и ошибка показываются в статистике. Если все источники недоступны,
запуск завершается ошибкой и предыдущие подписки сохраняются. Удаление URL из sources.txt исключает его из следующей сборки.

Дубли сравниваются без отображаемого имени, с нормализацией порядка параметров, регистра адреса,
кодирования авторизации и псевдонима hy2. На первом этапе разные параметры подключения сохраняются отдельно;
неизвестные параметры не отбрасываются. Затем применяется описанное ниже удаление повторных IP/доменов.
Сборщик проверяет формат, но **не проверяет подключение, скорость или доступность VPN**.

## Локальный запуск

Требуется Python 3.12 или новее; сторонних зависимостей нет.

```sh
python -m unittest -v
python collect.py
```

Источник примера структуры: https://codeberg.org/anonymouskeys/anonymouskeys

## Объединение и удаление повторных IP

Все источники из sources.txt объединяются каждые 4 часа. После удаления дублей конфигураций остается одна запись на IP независимо от порта и протокола; для доменных адресов — одна запись на имя домена. DNS-разрешение не выполняется. IPv6 нормализуется, IPv4-mapped IPv6 объединяется с IPv4. Выбирается первая конфигурация по порядку источников и записей в них, без оценки работоспособности. Общий список отсортирован по протоколам. Отдельные протокольные файлы являются разделами того же списка.

[Скачать общий TXT](https://github.com/DEGI94/vpn_fortuna/releases/download/downloads/vpn_fortuna.txt). В том же релизе доступны TXT по протоколам (`vless.txt`, `vmess.txt`, `trojan.txt`, `hysteria2.txt`, `tuic.txt`, `ss.txt` при наличии записей). Все названия конфигураций — @vpn_fortuna.

## NekoBox

Для NekoBox используйте [отдельную подписку](https://raw.githubusercontent.com/DEGI94/vpn_fortuna/main/subscriptions/nekobox/all.txt). Имена содержат @vpn_fortuna, протокол и стабильный идентификатор, чтобы избежать медленной обработки одинаковых имен в клиенте. Параметры подключения не изменены.

[Первая часть на 500 записей](https://raw.githubusercontent.com/DEGI94/vpn_fortuna/main/subscriptions/nekobox/part-001.txt). Все части находятся в subscriptions/nekobox и обновляются вместе с общим списком каждые 4 часа.
